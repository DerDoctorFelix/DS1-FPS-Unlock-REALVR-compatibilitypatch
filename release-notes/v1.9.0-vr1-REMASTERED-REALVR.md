# Dark Souls: Remastered, FPS Unlock v1.9.0-vr1 (R.E.A.L. VR compatibility fork)

Unofficial fork of DS1 FPS Unlock 1.9.0 by zofrea1, for playing Dark Souls: Remastered in VR with Luke Ross's R.E.A.L. VR (not included) while keeping the unlocker's physics fixes. Files: `dinput8.dll` and `DSR-FPS-Unlock.ini`, next to `DarkSoulsRemastered.exe` (R.E.A.L. VR's `dxgi.dll` stays). Steam build 1.03.1 only (SHA-1 `9150CC63C617332ED3C2C66E7566ED67E3292DA0`). Tested with R.E.A.L. VR 2607.31.1.

**Offline play only.** Online play is blocked by default (`BlockOnline`). Remove all mods before playing online.

## New

- **`ExternalFrameUnlock`** (on in the INI): R.E.A.L. VR keeps control of the frame rate and its time steps are passed through. The original mod scaled them a second time, which made the game run in slow motion. The physics fixes follow the step the game really uses, so with R.E.A.L. VR you get, for example, no permanent sprint slowdown after grazing a wall.
- **`ReplaceRetailSteps`**: with `ExternalFrameUnlock`, steps that are still the game's fixed 1/60 s are replaced by the measured frame time. Set `false` to pass everything through.
- **The fixes install next to R.E.A.L. VR:** the memory for the fixes is now found above and below the game image and shared in 4 KB pages. Before this, most fixes failed with `Win32=487` when R.E.A.L. VR was loaded.
- **Sprint fix watchdog:** checks every 2 s that the wall graze fix is still in place and re-applies it if needed (logged once a minute).
- **`NoLockOnRecenter`** (on): lock-on (R3) with nothing to lock onto no longer swings the camera behind the character.
- **`SkipIntro`** (on): skips the start-up logos.
- **`BlockOnline`** (on): the game cannot reach FromSoftware's servers. It works even with `FPSUnlock = false`.
- **`FixMouse`, `FixHavokStep`:** switches for two parts of the original that were always on.
- **`CameraProbe`** (off): camera diagnostics.

## Changed

- The VR preset sets `FixCamera = false`, so the follow camera stays tight around the character as with R.E.A.L. VR alone. Use `true` for 2D.
- `MaxFPS` (still 120) does nothing with `ExternalFrameUnlock`, because R.E.A.L. VR sets the frame rate.

Unchanged from 1.9.0: every physics, camera, animation, HUD and timing fix, and the whole Prepare to Die Edition part.
